# Rung Chuông Vàng - Toán 12

Trò chơi quiz đơn giản cho học sinh Toán 12, phiên bản tĩnh (front-end) dựa trên HTML/CSS/JS.

- File chính: `index.html`.
- Bảng xếp hạng được lưu trên `localStorage` của trình duyệt (không có backend ở phiên bản này).

Hướng dẫn chạy:
1. Mở `index.html` trong trình duyệt (hoặc bật GitHub Pages trên repository để xem trực tiếp).
2. Nhập tên, chọn level và bấm BẮT ĐẦU.

Gợi ý cải tiến tiếp theo (mình có thể làm giúp):
- Thêm backend (Node/Express) để lưu bảng xếp hạng persistently.
- Giao diện admin để thêm/sửa câu hỏi.
- Triển khai GitHub Pages hoặc một action để deploy tự động.
